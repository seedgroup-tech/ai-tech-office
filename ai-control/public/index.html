Conseils pour mieux utiliser l'IA

  • Gardez les longues tâches pour un modèle puissant, et utilisez un modèle plus léger pour les tâches simples.
  • Regroupez vos questions en une seule demande plutôt que plusieurs petites demandes.
  • Réutilisez une conversation existante quand elle porte déjà le bon contexte, au lieu de tout recoller.
  • Rattachez chaque usage à son projet : cela permet de répartir les coûts justement.

Les abonnements et crédits sont des dépenses. Les usages API sont des tokens, pas des dépenses : la dépense réelle d'un projet n'est qu'une estimation (tokens × coût réel du token) qui répartit vos dépenses, sans jamais s'y ajouter.

    La dépense réelle d'un projet est estimée ainsi : coût réel moyen du token (vos dépenses réelles ÷ l'ensemble des tokens, hors relectures de cache) × les tokens du projet. Tous les tokens sont comptés au même prix, quel que soit le modèle : c'est une approximation. Par défaut, la page montre le cumul à ce jour. Un mois, les 7 derniers jours ou une plage de dates s'appuient sur les relevés quotidiens (un chaque soir, depuis le 18 novembre 2026) : avant cette date, seul le total de chaque session est connu et il n'est pas réparti dans le temps. Les agents des tâches planifiées sont comptés à part, dans « XADIKOA agents » et « SSU agents ». Les relectures de cache (très nombreuses, très peu coûteuses) ne sont pas comptées.
